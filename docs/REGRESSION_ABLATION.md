# 定数回归特征消融报告

实验日期：2026-09-17。本文保存对子特征方案的探索性评估，以及 regression_beta 采用七维二次设计的依据。

## 结论

七维 raw 的二次回归是这批实验中较稳妥、复杂度较低的起点。十九维子特征替换没有明确改善留出误差；七维加五个补充量也没有一致收益。单加 Cumulate 最大有效长度降低了开发集 CV RMSE，但留出集几乎持平。三、四次更容易过拟合和外推失稳。

因此 regression_beta 保留七维 raw → StandardScaler → 二次 PolynomialFeatures → Ridge 的训练链路，继续保留预测后附加 fitted_constant、scorer 映射和独立雷达选轴。统计提取、任意子特征训练选择和消融脚本留在实验分支，不进入 beta 的分析接口。

## 数据和评估方式

冻结的日本定数总表共有 1,886 张谱面，明确匹配标签 1,690 张；其余 196 张未纳入训练。只对有标签谱面补算统计，未重新抓取定数。第一轮补算后七维 raw 与旧表逐项一致；增量轮原有 83 个 raw 字段也逐项一致。两轮均无分析失败或标题变化。

- 随机种子 42，按展示等级分层、不按歌曲分组；开发集 1,352 张，留出集 338 张。
- 开发集内使用五折 StratifiedKFold；极少数等级不足五折，sklearn 提示部分折缺少该等级。单样本等级留在开发集。
- 每个特征组分别固定二、三、四次；Ridge alpha 候选为 0.1、1、10，全部组合均选中 10。
- StandardScaler 在每折训练部分拟合；GridSearchCV 依据各折 RMSE 的均值选型。
- 所有特征组使用相同样本、相同行顺序和相同开发/留出/CV 划分，脚本逐组校验。
- model.json 在全部标签上重拟合；表中的留出指标对应只在开发集训练的 evaluation_model.json。
- 同一留出集已被多轮观察，这些数值属于探索性比较，不能作为后续特征迭代的独立最终评估。

## 局限与后续参考

- 这只评估了当前定义、当前多项式与当前正则范围，不能推出子特征在其他模型中无效。所有最佳 alpha 都落在候选上界，未来若再实验，可在开发集内独立评估更强正则。
- 原七维已编码最强配置、选峰、长度和并发修正。均值、分位数并不能完整替代这些聚合关系。
- 新统计量并非全部独立：RMS、均值和总体标准差存在确定关系；多组 count 重复；部分总量受谱长影响。
- beta 选择更小模型是基于效果与接入成本的取舍，不是宣称七维具有统计显著优势。最终服务效果需要新谱面或未参与迭代的数据验证。

## 核验与复现

归档分支中的 `scripts/compare_constant_regression.py` 直接定义实验组、阶数、alpha、seed 和折数，不增加特征选择 CLI。第一轮十九维的具体列表也保存在其 comparison.json 中。补算脚本保存在各 outputs 实验目录的 build_features.py。

六个实验 A 模型和二十一个实验 B 模型都在关闭 site-packages 的 Python 中完成测试向量验证，并抽查每个模型八个留出样本及三个最大误差样本，与 sklearn 的预测一致。实验 A 最大差异约 2.21e-13，实验 B 约 8.18e-14；详细核验分别见 validation.json。

报告只保存汇总，不提交逐曲标签、原谱、封面、音频或训练产物。
